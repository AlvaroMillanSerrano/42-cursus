# FLY-IN

---

## Description

Fly-in is a project with the aim of developing a program capable of recieving a file containing a map with different attributes and drones and being capable of solving the map by delivering all the drones to the end.

---

## Instructions

In order to compile and use this program, yu can use the makefile options:

- make install: installs all the dependencies from the program
- make run: runs the program
- make debug: runs the program in debug mode
- make clean: removes and cleans __pycache__
- make lint: search for mypy and flake8 errors
- make lint-strict: search for mypy and flake8 errors in strict mode

example:
```shell
    /make run MAP=maps/easy/01_linear_path.txt
```
